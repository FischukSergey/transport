# Транспортировка газа — как устроен проект

Читай план текущего спринта, контракт и чеклист. Концепция задаёт границы; если абзац в ней старее контракта, верь контракту.

## Статус

Кода ещё нет. Спринты **1–9** описаны в `docs/`, ни один не начат. Не начинай спринт, пока пользователь его не назвал.

Порядок концепции: движок (2–3), база и импорт (4–5), расчёт и отчёты (6–7), аномалии и exe (8–9). Прогноз в эти спринты не входит.

Документы спринта N: `docs/sprint-N-plan.md`, `sprint-N-checklist.md`, `contract-sprint-N.md`, `known-limitations-sprint-N.md`. Журнал — `REPORT.md`.

## Стек

Python 3.13 (`python3`, `pip3`), пакет `src/transport`. Окно — PySide6. База — один файл SQLite. Деньги и объёмы — `Decimal`, копейка `ROUND_HALF_UP`.

Слои: `ui` → `application` → `domain`. Рядом `ingest`, `quality`, `storage`. `domain` не импортирует Qt, sqlite3, openpyxl и pandas.

Команды только через `Taskfile.yml`: `task lint`, `task test`, `task fmt`, `task run`, `task tools:install`. Сборка exe — PyInstaller на `windows-latest`, артефакт `Transport.exe` (спринт 9).

## Расчёт

- Население не считать. Спецнадбавка для него не задаётся.
- Группа 1а есть всегда. Группа — по годовому объёму, граница «включительно» у большего номера.
- Сверхлимит — одна цифра, м³, на потребителя за месяц. Коэффициент сезона на 1-е число: апрель 1,5, сентябрь 1,1. Коммунально-бытовые: 1. На спецнадбавку коэффициент не умножать.
- Нет ставки группы — стоимость не подставлять.
- Спецнадбавка: регион + группа транспортировки.
- Закрытый месяц хранит один прогон. Повторное закрытие его заменяет. Импорт расчёт не запускает.

## Не делать

Прогноз до конца года, посуточный сверхлимит, историю прогонов, тариф группы 8, транзит, переход имущественных прав, собственные нужды, расчёт самого тарифа ГРО, Docker в поставке Windows.

## Документы при смене поведения

Вместе с кодом обнови `docs/contract-sprint-N.md` того спринта, чьё поведение меняется. Чеклист `[x]` только после проверки. DoD — после `task lint`, `task test` и демо из плана.
