# Транспортировка газа — как устроен проект

Читай план текущего спринта, контракт и чеклист. Концепция задаёт границы; если абзац в ней старее контракта, верь контракту.

## Статус

**Sprint 1 закрыт:** каркас пакета, окно-заглушка, `task lint` / `task test`, workflow на pull request в `main` и на push в `main`. **Sprint 2 закрыт:** `group_of`, `month_charges`, `consumer_total`, эталон января группы 5 — 46 030,30 без НДС. Объём в тыс. м³. **Sprint 3 закрыт:** `transition_charges`, `year_end_reimbursement`, январь группы 5 остаётся 46 030,30. Тесты синтетические. Момент перехода — загрузка, спринт 5. **Sprint 4 закрыт:** схема SQLite, справочники и ставки в окне, расчёт из окна не запускается. **Sprint 5 закрыт:** годовой план и факт месяца загружаются. Расхождения факта ждут ручного акцепта и карточек не создают. Расхождение группы плана акцептуется выбором группы файла или расчётной и переживает повторную загрузку того же плана. Загрузка факта пишет список переходов группы и `point_group` не меняет. Дополнительное соглашение в план не пишется. Общий профиль колонок не делается. **Sprint 6 начат:** снимок месяца собирается из базы, `close_month` вызывает движок по отметке загрузки и прогон не пишет. Спецнадбавка берётся по региону точки: первые две цифры кода, карточка его не правит. Первое окно открывает разделы. Справочники — отдельное окно. Загрузка данных — своё окно: план, факт и вкладка допсоглашения. Акцепт группы файла или расчётной и расхождения факта без карточек уже есть. Документ допсоглашения пишет покупателя, договор, точку, годовой объём и группу на 1 января, переименовывает точку без смены кода. Файл допсоглашения не читается, на двенадцать месяцев объём не раскладывается, строка документа в стоимость месяца не входит. Спринты **7–9** не начаты.

Порядок концепции: движок (2–3), база и импорт (4–5), расчёт и отчёты (6–7), аномалии и exe (8–9). Прогноз в эти спринты не входит.

Документы спринта N: `docs/sprint-N-plan.md`, `sprint-N-checklist.md`, `contract-sprint-N.md`, `known-limitations-sprint-N.md`. Журнал — `REPORT.md`.

## Стек

Python 3.13 (`python3`, `pip3`), пакет `src/transport`. Окно — PySide6. База — один файл SQLite. Деньги и объёмы — `Decimal`, копейка `ROUND_HALF_UP`.

Слои: `ui` → `application` → `domain`. Рядом `ingest`, `quality`, `storage`. `domain` не импортирует Qt, sqlite3, openpyxl и pandas.

Команды только через `Taskfile.yml`: `task lint`, `task test`, `task fmt`, `task run`, `task tools:install`. Сборка exe — PyInstaller на `windows-latest`, артефакт `Transport.exe` (спринт 9).

## Расчёт

- Население не считать. Спецнадбавка для него не задаётся.
- Группа 1а есть всегда. Граница «включительно» у большего номера. Шкала и коэффициенты — константы методики в `transport.parameters`, в движок приходят параметрами. Тариф и спецнадбавка берутся из таблиц. В начале года группа точки назначается по годовому плану и пишется в таблицу. Месячный расчёт читает таблицу.
- База месяца — объём минус оба объёма сверхлимита: объём уже включает сверхлимит.
- Сверхлимит — два объёма с коэффициентами 1,1 и 1,5. Движок половины месяца не делит: это только исходные данные апреля и октября. Коммунально-бытовые: оба объёма с коэффициентом 1. Ставка сверхлимита округляется до копейки до умножения на объём. Спецнадбавка — от всего объёма месяца, без коэффициента. Несколько договоров одной точки округляются по отдельности, строка точки — сумма уже округлённых сумм.
- Момент перехода определяет загрузка данных. Расчёт его не ищет. Точку более дешёвой группы считает отдельная функция, пока тариф не станет положительным. Возмещение по более дорогой группе — отдельная процедура один раз, по базе без сверхлимита, без записи группы на следующий год.
- Нет ставки группы — пробел, стоимость не подставлять. Население на входе — отказ `population_excluded`, без строки. НДС — отдельная сумма и только по флагу. Итог потребителя — сумма уже округлённых строк.
- Спецнадбавка: регион и период года. В расчёт входит уже выбранная ставка.
- Закрытый месяц хранит один прогон. Повторное закрытие его заменяет. Импорт расчёт не запускает.

## Не делать

Прогноз до конца года, посуточный сверхлимит, историю прогонов, тариф группы 8, транзит, переход имущественных прав, собственные нужды, расчёт самого тарифа ГРО, Docker в поставке Windows.

## Документы при смене поведения

Вместе с кодом обнови `docs/contract-sprint-N.md` того спринта, чьё поведение меняется. Чеклист `[x]` только после проверки. DoD — после `task lint`, `task test` и демо из плана.
