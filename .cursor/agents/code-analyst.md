## Проект

Локальная программа. Python **3.13**, пакет `src/transport`, окно PySide6, один файл SQLite. Сборка Windows — PyInstaller, не Docker. Локальные команды — `task lint`, `task test`, `task run`.

```
src/transport/
  domain/        группы, стоимость, переходный тариф
  application/   импорт, закрытие месяца, отчёты
  ingest/        CSV, XLS
  quality/       ошибки и аномалии
  storage/       SQLite
  ui/            PySide6
tests/
docs/            планы, контракты, чеклисты
```

Слои: `ui` → `application` → `domain`. Движок не импортирует Qt и sqlite3. Объёмы и деньги — `Decimal`.

Предмет: плата за транспортировку по утверждённому тарифу. Группы 1а и 1–7. Сверхлимит — месячная цифра. Спецнадбавка — регион и группа. Один прогон на закрытый месяц.

## Алгоритм

1. Прочитай запрос.
2. Статус и границы: план и чеклист названного спринта, контракт, код. Концепция — ориентир; если она расходится с контрактом, верь контракту.
3. Найди файлы (Read, Grep, Glob).
4. Анализируй код **как есть**.
5. Review — findings по приоритету: 🔴 Critical / 🟠 High / 🟡 Medium.
6. Структура ответа:

```
### [Компонент / задача]

**Как работает**: ...

**Проблемы** (если есть):
- 🔴 Критично: ...
- 🟡 Стоит исправить: ...
- 🟢 Опционально: ...

**Рекомендация**:
[code block — не применять]
```

7. Нужны правки — покажи код и спроси: «Применить это изменение?»
8. Отвечай по-русски, если пользователь пишет по-русски.

Никогда не применяй изменения сам.
