# Sprint 4 Checklist

Источник: [`sprint-4-plan.md`](sprint-4-plan.md).

## 1) База

- [x] Пустой файл получает схему.
  Примечание: `open_database` создаёт таблицы при открытии и пишет `user_version` 4. Повторное открытие их не дублирует. Файл с большим номером не открывается. Файл версии 1 или 2 теряет таблицу подтверждения и ставки не с 1-го числа. Файл версии 3 переносит точку под договор.
- [x] Таблицы справочников, ставок, факта, прогона и замечаний.
  Примечание: учётная единица — точка. Помесячный план справочный. Группа — цепочка дат. Входящий остаток на точке.
- [x] Файл базы не попадает в git.
  Примечание: `.gitignore` закрывает `transport.database`, `*.sqlite`, `*.sqlite3`, `*.db`.
- [x] Повторное сохранение обновляет строку и не пишет историю версий.
  Примечание: тот же код региона и тот же годовой план обновляют строку. Новая дата группы добавляет период, прежняя остаётся.

## 2) Ставки

- [x] Тарифы групп 1а и 1–7.
  Примечание: `tariff_for_month` берёт наибольшую дату не позже 1-го числа. Группа 8 не записывается. Следующая дата закрывает интервал: сентябрь группы 5 остаётся на ставке 1 января, октябрь берёт ставку 1 октября.
- [x] Спецнадбавка по региону и группе.
  Примечание: `surcharge_for_month`. Ставка другого региона или другой группы не подходит.
- [x] Спецнадбавка для населения не сохраняется.
  Примечание: `population` и `8` дают `RateGroupRejected`, строка не создаётся.
- [x] Ставка не с 1-го числа не записывается.
  Примечание: 15 июля и 2 октября дают `RateDateRejected`, строка не создаётся. Июль остаётся на тарифе 1 января.

## 3) Экраны

- [x] Регион, потребитель, точка, договор.
  Примечание: вкладки окна пишут карточки через `Catalog`. Регионы — последняя вкладка. Даты на экране — дд/мм/гг. Пустая база получает тестовые регионы, тарифы и спецнадбавку. Путь к базе запоминается в `transport.database`.
- [x] Тип потребителя: промышленный, коммунально-бытовой, население.
  Примечание: карточка потребителя предлагает эти три типа.
- [x] Ленты тарифа и спецнадбавки.
  Примечание: группы 1а…7. Спецнадбавка «население», дата не с 1-го числа и ставка не с двумя знаками показывают пояснение и строку не пишут. Запятая и точка принимаются.
- [x] SQL остаётся в репозитории, не в окне.
  Примечание: окно вызывает `Catalog`. В `src/transport/ui` нет `sqlite3` и `SELECT`.

## 4) Тесты

- [x] Репозитории на временной SQLite.
  Примечание: запись справочников и ставок идёт во временный файл. Повторное открытие и подъём с версии 1 тоже.
- [x] Выбор ставки на 1-е число месяца.
  Примечание: сентябрь группы 5 — ставка 1 января, октябрь — ставка 1 октября. Дата не с 1-го числа в таблицу не попадает.

## 5) DoD

- [x] Контракт [`contract-sprint-4.md`](contract-sprint-4.md) совпадает со схемой.
  Примечание: таблицы и ключи те же, что в `schema.py`, номер 3. Месяц 1–12, `vat_rate` может быть пустым, строка результата одна на прогон, точку, год и месяц. Демо двух регионов, промышленного потребителя, точки, договора, тарифа 1а, спецнадбавки и отказа для населения закрывают тесты каталога и окна.
- [x] Зафиксированы [`known-limitations-sprint-4.md`](known-limitations-sprint-4.md).
  Примечание: расчёт из окна — спринт 6, план и факт — спринт 5, тариф остаётся ручным. Проверка закрытого месяца в запись не встроена.
