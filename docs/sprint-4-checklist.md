# Sprint 4 Checklist

Источник: [`sprint-4-plan.md`](sprint-4-plan.md).

## 1) База

- [ ] Пустой файл получает схему.
- [ ] Таблицы справочников, ставок, факта, прогона и замечаний.
- [ ] Файл базы не попадает в git.
- [ ] Повторное сохранение обновляет строку и не пишет историю версий.

## 2) Ставки

- [ ] Тарифы групп 1а и 1–7.
- [ ] Спецнадбавка по региону и группе.
- [ ] Спецнадбавка для населения не сохраняется.
- [ ] Ставка не с 1-го числа требует подтверждения.

## 3) Экраны

- [ ] Регион, потребитель, точка, договор.
- [ ] Тип потребителя: промышленный, коммунально-бытовой, население.
- [ ] Ленты тарифа и спецнадбавки.
- [ ] SQL остаётся в репозитории, не в окне.

## 4) Тесты

- [ ] Репозитории на временной SQLite.
- [ ] Выбор ставки на 1-е число месяца.

## 5) DoD

- [ ] Контракт [`contract-sprint-4.md`](contract-sprint-4.md) совпадает со схемой.
- [ ] Зафиксированы [`known-limitations-sprint-4.md`](known-limitations-sprint-4.md).
