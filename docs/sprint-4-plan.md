# Sprint 4 — база и справочники

Источник: [`../архитектура.md`](../архитектура.md) «Модель данных»; [`../функционал.md`](../функционал.md) «Справочники», «Тарифы и спецнадбавка».

## 1) Цель

Пользователь ведёт регионы, потребителей, точки, договоры, тарифы и спецнадбавку в окне. Данные лежат в одном файле SQLite. Расчёт из окна ещё не запускается.

## 2) Входные условия

Sprint 3 закрыт: движок считает период по снимку. Окно всё ещё заглушка.

## 3) Границы

### Входит

- схема SQLite и репозитории;
- экраны справочников, тарифов и спецнадбавки;
- ручное создание и правка;
- группа 1а в сетке тарифов;
- спецнадбавка по региону и группе, без строки для населения;
- дата начала ставки только 1-е число, иной день не записывается;
- тип «население» в карточке потребителя.

### Не входит

- импорт файлов;
- закрытие месяца;
- план-факт.

## 4) Backlog

### A. Схема

- регион, потребитель, точка, договор, допсоглашение, годовой и помесячный план, история группы точки;
- тариф транспортировки и спецнадбавка, дата начала только 1-е число;
- заготовки таблиц факта, прогона и замечания без экрана расчёта.

### B. Репозитории

- чтение и запись справочников;
- цепочка ставок: следующая дата той же группы (и того же региона у спецнадбавки) закрывает интервал;
- повторное сохранение обновляет текущую строку, версии прогонов не создаются.

### C. Экраны

- список и карточка региона, потребителя, точки, договора;
- лента тарифов по группам 1а и 1–7;
- лента спецнадбавки по региону и группе;
- попытка завести спецнадбавку для населения не сохраняется, на экране видно пояснение;
- дата начала не 1-е число не сохраняется, на экране видно пояснение.

### D. Тесты

- репозитории на временном файле SQLite;
- интервал ставки на 1-е число месяца;
- запрет спецнадбавки населения.

## 5) Техрешения

- Файл базы выбирается при старте и запоминается в настройках рядом с программой. В git файл базы не входит.
- Схема создаётся кодом при открытии пустого файла.
- Экраны вызывают репозитории через прикладной слой, SQL в окне нет.
- Движок по-прежнему не импортирует storage.

## 6) DoD

- в пустом файле можно завести два региона, потребителя, точку, договор, тариф группы 1а и спецнадбавку;
- контракт — [`contract-sprint-4.md`](contract-sprint-4.md).

## 7) Демо

1. Открыть программу и создать файл базы.
2. Завести регион, промышленного потребителя, точку и договор.
3. Ввести тариф группы 1а и спецнадбавку этого региона и группы.
4. Показать отказ сохранить спецнадбавку для населения.

## 8) Риски

- правка справочника задним числом расходится с будущим прогоном → в этом спринте прогонов ещё нет; правило «закрытый месяц не меняется, пока его не закроют заново» фиксируется в контракте и проверяется в спринте 6.
