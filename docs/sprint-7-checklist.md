# Sprint 7 Checklist

Источник: [`sprint-7-plan.md`](sprint-7-plan.md).

## 0) Точка подключения

- [x] Вкладка «Точка»: год и выбор точки по коду или адресу.
  Примечание: окно «Отчеты» открывается с первого экрана.
- [x] Шапка: код, адрес, регион, покупатель, группа на 1 января.
- [x] План года по договорам: годовой объём. Суммы транспортировки и спецнадбавки в эту таблицу не выводятся.
  Примечание: договор карточки без объёма остаётся в списке с пустым объёмом. Строка «Точка» — сумма объёмов.
- [x] Переход группы, если отметка есть. Иначе «переходов нет».
- [x] Факт по месяцам из прогона этого месяца. Месяц без прогона — «не закрыт».
  Примечание: строка того же месяца внутри более позднего прогона фактом не считается.
- [x] Кнопка «Сохранить» пишет тот же лист xlsx.
- [x] Население в суммы не входит.
- [x] Отчёт не вызывает смену группы.
  Примечание: `task lint` без замечаний. `task test`: 205 passed.

## 1) План-факт

- [ ] План по начальной группе и ставке месяца.
- [ ] Факт из строк прогона.
- [ ] Отклонение объёма и стоимости.
- [ ] Срезы: весь объём, группа, потребитель, каждый по региону.
- [ ] Месяц и нарастающий итог.
- [ ] Незакрытые месяцы перечислены, а не заменены нулём.
- [ ] Населения в срезе нет.

## 2) Статистика

- [ ] Объём, стоимость, спецнадбавка и её доля.
- [ ] Средняя ставка, при нулевом объёме поле пустое.
- [ ] Число переходов и направление.
- [ ] Доля сверхлимита.

## 3) Тесты

- [ ] Кейс группы 5: план и факт.
- [ ] Сумма двух месяцев равна нарастающему итогу.
- [ ] Отчёт не вызывает смену группы.

## 4) DoD

- [ ] Контракт [`contract-sprint-7.md`](contract-sprint-7.md) совпадает с экранами.
