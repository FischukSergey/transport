# Sprint 7 Checklist

Источник: [`sprint-7-plan.md`](sprint-7-plan.md).

## 1) План-факт

- [ ] План по начальной группе и ставке месяца.
- [ ] Факт из строк прогона.
- [ ] Отклонение объёма и стоимости.
- [ ] Срезы: весь объём, группа, потребитель, каждый по региону.
- [ ] Месяц и нарастающий итог.
- [ ] Незакрытые месяцы перечислены, а не заменены нулём.
- [ ] Населения в срезе нет.

## 2) Статистика

- [ ] Объём, стоимость, спецнадбавка и её доля.
- [ ] Средняя ставка, при нулевом объёме поле пустое.
- [ ] Число переходов и направление.
- [ ] Доля сверхлимита.

## 3) Тесты

- [ ] Кейс группы 5: план и факт.
- [ ] Сумма двух месяцев равна нарастающему итогу.
- [ ] Отчёт не вызывает смену группы.

## 4) DoD

- [ ] Контракт [`contract-sprint-7.md`](contract-sprint-7.md) совпадает с экранами.
- [ ] Зафиксированы [`known-limitations-sprint-7.md`](known-limitations-sprint-7.md).
