# Known Limitations — Sprint 9

Ограничения версии, которая собирается в exe. Это не долг следующего обязательного спринта.

## Поставка

**Exe не подписан и не обёрнут в установщик.** Windows может предупреждать при запуске.

**Сборка exe только на GitHub Actions.** На Mac кросс-сборка Windows не поддерживается.

## Предметная область

**Население не считается,** спецнадбавка для него не задаётся.

**Сверхлимит приходит одной цифрой на месяц.** Посуточный ряд и коэффициент внутри месяца не восстанавливаются. Апрель считается с коэффициентом 1,5, сентябрь — с 1,1, по сезону на 1-е число.

**Прогноза до конца года нет.** Чтобы он появился отдельным этапом, нужны сезонность, прогноз погоды и история аналогичных периодов прошлых лет.

**История прогонов не хранится.** У месяца один результат, повторное закрытие его заменяет.
