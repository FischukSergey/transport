# Sprint 8 Checklist

Источник: [`sprint-8-plan.md`](sprint-8-plan.md).

## 1) Правила

- [ ] Структурные коды на приёмке файла.
- [ ] Связи: регион, план и факт, дыра и пересечение ставок.
- [ ] Предметные правила: итог с начала года, ставка группы.
- [ ] Население — исключение, соседей не блокирует.
- [ ] Аномалия: порог к договору и межквартильный размах с третьего месяца.

## 2) Журнал

- [ ] Серьёзность, код, ссылка, текст.
- [ ] Переход к потребителю или ставке.
- [ ] Повторная проверка заменяет замечания и не копит историю.
- [ ] Ошибка блокирует закрытие, аномалия нет.

## 3) Статистика

- [ ] У аномального месяца есть признак.
- [ ] Сумма строки не изменилась.

## 4) Тесты

- [ ] Факт без плана блокирует закрытие.
- [ ] Выброс объёма закрывается и помечается.
- [ ] `quality` не импортирует Qt.

## 5) DoD

- [ ] Контракт [`contract-sprint-8.md`](contract-sprint-8.md) совпадает с кодами.
- [ ] Зафиксированы [`known-limitations-sprint-8.md`](known-limitations-sprint-8.md).
