# Sprint 3 Checklist

Источник: [`sprint-3-plan.md`](sprint-3-plan.md).

## 1) Начальная группа

- [ ] Группа точки приходит из таблицы. План в расчёт не входит.

## 2) Смена группы

- [ ] В течение года смена только когда факт превысил верхнюю границу группы из таблицы.
- [ ] До декабря факт ниже границы группу месяца не меняет.
- [ ] По итогам года более дорогая группа: возмещение недоплаты по базе без сверхлимита, группа в таблице не меняется.
- [ ] Вычет сверхлимита не больше 10 % базы.
- [ ] Запрет смены для нового потребителя на неполном году и при запрете в договоре.

## 3) Тариф и сверхлимит

- [ ] Переходный тариф месяца смены.
- [ ] Отрицательный тариф переносится на следующий месяц услуг.
- [ ] Спецнадбавка берётся по группе этого месяца.

## 4) Тесты

- [ ] Кейс 32 800 без изменения суммы.
- [ ] Переход в более дешёвую группу.
- [ ] Вычет 10 % удерживает группу.
- [ ] След содержит объём отнесения и формулу перехода.

## 5) DoD

- [ ] Контракт [`contract-sprint-3.md`](contract-sprint-3.md) совпадает с расчётом периода.
- [ ] Зафиксированы [`known-limitations-sprint-3.md`](known-limitations-sprint-3.md).
