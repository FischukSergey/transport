# Sprint 5 Checklist

Источник: [`sprint-5-plan.md`](sprint-5-plan.md).

## 1) Разбор

- [ ] CSV и XLS.
- [ ] Пять видов файлов из контракта.
- [ ] Сопоставление колонок и сохранённый профиль вида.
- [ ] Пустой код, неверный тип, дубликат, отрицательный объём видны до записи.

## 2) Приёмка

- [ ] В базу попадают только подтверждённые строки.
- [ ] Загрузка не вызывает движок.
- [ ] Накопительный итог не раскладывается на предыдущие месяцы.
- [ ] Население сохраняется как тип и помечается исключением.
- [ ] Спецнадбавка населения не записывается.
- [ ] Повторная загрузка обновляет данные и не меняет уже записанный прогон.

## 3) Момент перехода

Загрузка записывает отметку и движок не вызывает. Закрытие месяца читает её в спринте 6.

- [ ] В течение года отметка более дешёвой группы только когда факт превысил верхнюю границу группы из таблицы.
- [ ] До декабря факт ниже границы отметку месяца не меняет.
- [ ] Вычет сверхлимита не больше 10 % факта с начала года.
- [ ] Новый потребитель на неполном году и запрет в договоре отметку перехода не получают.

## 4) Тесты

- [ ] Фикстуры CSV и XLS.
- [ ] Профиль колонок на втором файле того же вида.
- [ ] Вычет 10 % удерживает группу.

## 5) DoD

- [ ] Контракт [`contract-sprint-5.md`](contract-sprint-5.md) совпадает с приёмкой.
- [ ] Зафиксированы [`known-limitations-sprint-5.md`](known-limitations-sprint-5.md).
