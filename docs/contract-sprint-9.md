# Контракт Sprint 9

Источник: [`sprint-9-plan.md`](sprint-9-plan.md).

## 1) Решения спринта

- Поставка Windows — один файл `Transport.exe`.
- Рядом с exe программа создаёт свой SQLite, если файла ещё нет. Чужие данные в артефакт не входят.
- Контракты спринтов 2–8 этим спринтом не меняются.

## 2) Запуск

Mac, из корня репозитория после установки пакета:

`python -m transport`

Windows: запуск `Transport.exe` без установленного Python.

Окно то же, что у исходников: справочники, импорт, расчёт, план-факт, статистика, журнал.

## 3) CI

На каждый push:

- `task lint`;
- `task test`.

Сборка exe:

- агент `windows-latest`;
- PyInstaller;
- артефакт с именем `Transport.exe`;
- запуск вручную либо по тегу вида `v*`.

Docker в шагах сборки exe отсутствует.

## 4) Совместимость

Команда `python -m transport` из [`contract-sprint-1.md`](contract-sprint-1.md) сохраняется. Меняется только содержимое окна: это уже программа, не заглушка.
