# Sprint 9 — сборка Windows

Источник: [`../architecture.md`](../architecture.md) «Сборка и проверка»; [`../concept.md`](../concept.md) «Сборка».

## 1) Цель

Пользователь Windows получает один исполняемый файл. На Mac разработка идёт из того же кода. CI по-прежнему гоняет стиль и тесты, а сборка exe публикуется артефактом.

К концу спринта новый функционал не появляется. Собирается то, что закрыто в спринтах 1–8.

## 2) Входные условия

Спринты 1–8 закрыты по чеклистам: движок, база, импорт, закрытие месяца, отчёты, журнал.

## 3) Границы

### Входит

- PyInstaller, один exe;
- workflow `windows-latest`: сборка и загрузка артефакта;
- README: запуск на Mac, откуда взять exe, где лежит файл базы;
- `task lint` и `task test` на pull request в `main` и на push в `main` остаются зелёными;
- короткий сценарий на Mac: справочник, импорт фикстуры, закрытие месяца, план-факт.

### Не входит

- Docker в поставке Windows;
- прогноз;
- новые отчёты и формулы;
- установщик и подпись exe.

## 4) Backlog

### A. Сборка

- spec PyInstaller: окно без консоли, пакет `transport`, зависимости PySide6;
- база создаётся рядом с программой при первом запуске, в exe не зашивается чужой файл с данными;
- фикстуры тестов в exe не входят.

### B. CI

- текущий workflow вызывает `task lint` и `task test`;
- отдельный workflow сборки на `windows-latest` при теге или при ручном запуске;
- артефакт `Transport.exe`.

### C. README

- Mac: `.venv`, установка, `python -m transport`;
- Windows: скачать артефакт, запустить, файл базы рядом;
- что программа не считает: население, транзит, прогноз.

### D. Проверка

- exe на GitHub Actions стартует достаточно для дымового импорта модуля внутри сборки;
- локально на Mac сценарий демо проходит на фикстуре января.

## 5) Техрешения

- Сборка Windows только на GitHub Actions, не на Mac кросс-компиляцией.
- Docker на Mac можно использовать для pytest, если так удобнее. Workflow сборки exe Docker не вызывает.
- Имя артефакта одно, версия берётся из тега. Без тега ручной запуск кладёт артефакт в сборку workflow.

## 6) DoD

- артефакт `Transport.exe` скачивается из Actions;
- README описывает Mac и Windows;
- функционал спринтов 2–8 не изменился;
- контракт — [`contract-sprint-9.md`](contract-sprint-9.md).

## 7) Демо

1. На Mac пройти фикстуру января до план-факта.
2. Открыть Actions и показать артефакт exe.
3. Показать, что в README нет шага с Docker для Windows.

## 8) Риски

- PySide6 раздувает exe и ломает сборку скрытыми плагинами Qt → в спринте закладывается время на spec и один пустой запуск собранного файла на `windows-latest`.
- антивирус на Windows может задерживать неподписанный exe → в ограничениях это записано, подпись вне спринта.
