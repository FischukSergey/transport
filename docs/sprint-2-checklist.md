# Sprint 2 Checklist

Источник: [`sprint-2-plan.md`](sprint-2-plan.md).

## 1) Группа и объём

- [ ] Границы групп 1а и 1–7, включительно в сторону большего номера.
- [ ] Методы «факт», «договор», «смешанный».
- [ ] Последний месяц метода «договор»: выравнивание и возврат при отрицательном объёме.

## 2) Сверхлимит и спецнадбавка

- [ ] Сверхлимит читается готовой цифрой, м³.
- [ ] Апрель — коэффициент 1,5, сентябрь — 1,1.
- [ ] Коммунально-бытовой потребитель — коэффициент 1.
- [ ] Спецнадбавка по региону и группе, без коэффициента.
- [ ] Нет ставки спецнадбавки — пустая строка, база на месте.

## 3) Сборка

- [ ] Нет тарифа группы — пробел, стоимость не подставлена.
- [ ] Население — отказ, без строки стоимости.
- [ ] НДС отдельной суммой и только по флагу.
- [ ] Итог потребителя — сумма округлённых строк точек.
- [ ] `Decimal`, копейка, `ROUND_HALF_UP`.

## 4) Тесты

- [ ] Январь группы 5 → 32 800 без НДС.
- [ ] Тот же год методом «договор».
- [ ] Движок не импортирует Qt и SQLite.

## 5) DoD

- [ ] Контракт [`contract-sprint-2.md`](contract-sprint-2.md) совпадает с функциями.
- [ ] Зафиксированы [`known-limitations-sprint-2.md`](known-limitations-sprint-2.md).
