# Sprint 6 Checklist

Источник: [`sprint-6-plan.md`](sprint-6-plan.md).

## 1) Снимок

- [ ] Снимок собирается из базы, окно формулы не вызывает.
- [ ] Население не попадает в снимок и видно в готовности.
- [ ] Ставка берётся на 1-е число, неподтверждённая дата блокирует закрытие.
- [ ] Входящий остаток не восстанавливает предыдущие месяцы.

## 2) Прогон

- [ ] Успешное закрытие пишет один прогон со статусом «готов».
- [ ] Пробел тарифа не подставляет ставку.
- [ ] Повторное закрытие заменяет прогон и не оставляет второй.
- [ ] Прогоны других месяцев на месте.
- [ ] Закрытие месяца не меняет прогоны предыдущих месяцев.
- [ ] Заблокированная попытка не удаляет уже записанный прогон.

## 3) Экран

- [ ] Выбор года, месяца и НДС.
- [ ] Таблица с фильтром региона, группы и потребителя.
- [ ] Карточка со следом и переходным тарифом.
- [ ] Итог потребителя за месяц и с января.
- [ ] Расчёт не блокирует окно.

## 4) Тесты

- [ ] Кейс 32 800 через прикладной слой и временную базу.
- [ ] В таблице прогонов одна строка после двух закрытий.

## 5) DoD

- [ ] Контракт [`contract-sprint-6.md`](contract-sprint-6.md) совпадает со сценарием.
- [ ] Зафиксированы [`known-limitations-sprint-6.md`](known-limitations-sprint-6.md).
