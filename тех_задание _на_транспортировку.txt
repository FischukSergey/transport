Техническое задание

Программа для расчета стоимости транспортировки газа.

Входные данные - файл CSV или .xls
Алгоритм расчета - в skill агента name: raschet-transportirovki-gaza
Программа должна запускаться в среде Windows. Docker не предлагать.
Разработка будет вестись на Mac
Предположительный язык - Python
Хранение репозитория на Github
Build на гитхабе
Программа должна иметь графический интерфейс
Хранение данных желательно в безсеверной среде типа SQLite

Входные данные:
план транспортировки по потребителям на год для первоначального отнесения к группе потребителей
Тарифы на транспортировку с определенной даты. Обычно тарифы меняются два раза в год
Тарифы на специальную надбавку с определенной даты для определенного региона. Будет два региона.
Месячные показатели по объемам транспортировки по потребителям

При первоначальной загрузке будут загружены суммированные данные по потребителям с начала текущего года

Выходные данные:
расчетные данные по стоимости транспортировки газа по потребителям
Расчетная стоимость данных спецнадбавки по потребителям
Расчетный тариф для потребителей перешедших в новую группу

Программа должна выдавать:
план фактный анализ по всему объему, по группам, по потребителям в разрезе регионов
Статистические данные по всему объему, по группам, по потребителям в разрезе регионов

Программа должна уметь распарсить входные данные, провести их анализ - выявить ошибочные данные, определить аномалии и несоответствия

Программа должна уметь на основе исторических данных строить прогноз до конца календарного года.
